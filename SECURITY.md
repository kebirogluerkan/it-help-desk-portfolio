# Security and Privacy

- This repository contains only deterministic synthetic data.
- Do not upload production tickets, credentials, access tokens, email addresses, phone numbers, device serial numbers, internal IP addresses, or customer information.
- Redact usernames, local file paths, organization names, and machine identifiers from screenshots.
- Never place passwords, API keys, connection strings, or private certificates in the repository.
- Report accidental sensitive-data commits immediately and rotate exposed credentials before rewriting history.
